# FLIPPER-X-ESP32S3

App Store index and firmware port for FLIPPER X (ESP32-S3 N18R8).

## Hardware Target
- ESP32-S3 N18R8 (18MB Flash + 8MB Octal PSRAM)
- ILI9341 2.8" display (SPI) + SSD1306 OLED (I2C)
- 6-button navigation
